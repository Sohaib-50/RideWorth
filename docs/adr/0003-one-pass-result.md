# One-pass result

The demo has to convey the verdict, not teach a correction workflow. Text and mic both run straight through. The result shows the values that were used and the English offer note. There is no edit step and no recalculate. A vague place is explained in the note. A missing fare or place stops the money that depends on it and shows a clear message instead of a broken result. The wording of that message is an implementation choice.
